### 2.2 关键共性挑战

**稳定性灾难**：几乎所有工具均爆发严重 Bug。Claude Code 的 fork/subtask 导致上下文溢出、Codex 的 Windows 平台进程泄漏、Gemini CLI 的子代理挂起，用户从追求新功能转向抗议基础功能不可靠。

**安全与权限**：Agent 绕过权限、擅自执行破坏性命令成为高频 Bug。社区强烈要求实施**读写分离权限**、对特定命令族（如 `git clean`）精确授权，并确保 `AGENTS.md` 约束文件被强制执行。

**成本与可观测性**：子代理失控导致 Token 和费用指数级增长。用户要求**会话费用硬上限**、透明 Token 消耗明细、实时干预"刹车"机制。`Wattage` 等成本控制工具开始受到关注。

**跨平台鸿沟**：Windows ARM64 原生支持成为巨大缺口，多个工具因终端渲染、进程管理问题被用户集中投诉。
